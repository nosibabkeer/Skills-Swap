>  Project Objectives: The platform aims to make learning more accessible, interactive, and community-driven by connecting people based on the skills they can teach and the skills they want to learn.
 1- Create and manage their profiles.
2-Add skills they can teach.
3- Select skills they want to learn.
4- Search for other users based on their skills.
5- View user profiles and skill details.
6- Connect with other users for skill exchange.
7- Communicate and arrange skill-sharing sessions.
8- Track their learning and teaching activities.
